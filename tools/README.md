# Building and checking Humanity, Live

- `tools/tpl.html` is the source. `python3 tools/build.py` (run from `tools/`) writes `index.html` (CDN three.js) and `test.html` (local three.js for tests).
  It needs `mask.b64` and `topo.b64` next to it.
- Copy `tools/index.html` to `public/index.html` to ship.
- Stability check: `npm i three@0.128.0` inside `tools/`, `pip install playwright`, then `python3 tools/smoke.py`. It must print only PASS lines before anything is pushed.
- `public/changelog.json` feeds the "What's new" list in the app (newest first).

## Trading cards
- `public/cards.json` is generated by `tools/cards.js` (build.py runs it) from the page's own data (SP, BIG, DISC) and the public/*.json data files. Don't edit it by hand; new species, events, wonders, journeys, extinctions, storms and landforms become cards automatically.
- Seasons follow the world clock (see SEASONS in cards.js). A season's cards can only be earned while that era is playing; after that they can only be traded.
- The server side is in src/worker.js (`/api/cards/*`, tables ckey, cuser, card, offer, ipday). Event cards (`ev-*`) are only granted while the event is live. Trading needs Google sign-in (GOOGLE_CLIENT_ID var). Paid packs stay off until a STRIPE_SECRET exists.
